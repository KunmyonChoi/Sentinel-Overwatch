# 디자인 진실 — sentinel-tutorial

이 파일이 색·서체·자리의 유일한 출처다. 장면 파일은 여기서만 값을 가져온다.

## 왜 제품 팔레트를 그대로 쓰는가

영상이 제품과 다른 얼굴이면, 영상을 보고 제품을 열었을 때 같은 물건으로
보이지 않는다. 그래서 두 팔레트를 지어내지 않고 `frontend/src/index.css` 와
`docs/ux/build_tutorial_deck.py` 에서 쓰는 값을 그대로 가져왔다.

## 팔레트

### 초보자 (기본) — 해설·쉬운 화면 장면

| 역할 | 값 |
|---|---|
| 바탕 | `#eef3f0` |
| 카드 | `#ffffff` |
| 보조 면 | `#f5f8f6` |
| 글 | `#17221d` |
| 흐린 글 | `#5c6b64` |
| 강조 | `#0e7c6b` |
| 강조 연한 면 | `#d9ece7` |
| 선 | `#dfe7e3` |
| 진한 선 | `#c7d4ce` |
| 주의 | `#b8860b` |
| 위험 | `#b3261e` |

### 전문가 — 터미널·대시보드 장면

| 역할 | 값 |
|---|---|
| 바탕 | `#0a0f0d` |
| 형광 초록 | `#00ff41` |
| 흐린 초록 | `rgba(0,255,65,0.45)` |
| 위험 | `#ff0033` |
| 선 | `rgba(0,255,65,0.3)` |

**강조는 장면당 하나.** 초록을 여러 곳에 뿌리면 어디를 봐야 하는지 사라진다.

## 서체

- 본문·화면: `IBM Plex Sans KR`, 400/500/700. 대체 `Apple SD Gothic Neo, Malgun Gothic, system-ui`.
- 터미널·로그·설정 파일: `JetBrains Mono, Fira Code, monospace`.
- 한국어 줄바꿈은 항상 `word-break: keep-all`. 단어 중간에서 끊기면 읽는 속도가 떨어진다.

## 화면 분할 — 모든 장면이 지킨다

```
0 ─────────────────────────────────────── 1920
│                                          │
│            내용 영역  1920 × 860         │
│                                          │
860 ────────────────────────────────────────
│         자막 띠  1920 × 220              │
1080 ───────────────────────────────────────
```

- **자막 띠는 절대 움직이지 않는다.** 바탕 `#17221d`, 글 `#ffffff` 38px/1.55,
  좌우 여백 150px, 세로 가운데. 전문가 팔레트 장면에서도 같은 자리·같은 색이다.
  장면이 바뀌어도 눈이 자막을 다시 찾을 필요가 없어야 한다.
- 내용 영역의 좌우 안전 여백 150px, 위 아래 60px.
- 장 제목(눈썹 + 제목)은 왼쪽 위 고정: 눈썹 `left:150 top:70`, 제목 `left:150 top:112`.

## 자막 규칙

- 한 번에 한 문단. 문단이 바뀔 때 앞 문단은 사라지고 새 문단이 나타난다(겹치지 않는다).
- 두 줄을 넘기지 않는다. 넘으면 문단을 쪼갠다.
- 문단 하나가 화면에 머무는 시간 = `글자수 ÷ 5.3초 + 0.8초`.

## 모션

- 요소는 **도착하고 머문다**. 나갔다 들어오지 않는다.
- 기본 등장: `opacity 0→1` + `y 16→0`, 0.45s, `power2.out`.
- 한 문단에 도착하는 요소가 여럿이면 stagger 0.08s, 총 0.5s를 넘기지 않는다.
- 카메라(스케일·팬)는 쓰지 않는다. 이 영상에 카메라 워크는 없다.
- 글리치·슬램·플래시 없음. 설명서에 필요 없다.

## 화면 목업을 그릴 때

- 창틀: 흰 카드, `border-radius:18px`, 그림자 `0 24px 60px rgba(23,34,29,0.16)`,
  선 `1px solid #dfe7e3`. 상단 바 62px, 보조 면 색.
- 값은 **전부 지어낸 것**이어야 한다. 실제 호스트명·IP·계정명·포트 구성 금지.
  지어낸 값도 그럴듯해야 한다(예: `203.0.113.9` — 문서용 예약 대역).
- 토큰·비밀은 `••••••••` 로 가린다.
